## 🛠️ Proyectos destacados

### 🚀 Proyecto Intermodular ASIX

Proyecto desarrollado durante el ciclo formativo de Administración de Sistemas Informáticos en Red (ASIX), donde se integran diferentes tecnologías utilizadas en entornos empresariales reales.

El proyecto está dividido en varios miniproyectos:

- ☸️ Kubernetes Básico
- 📊 Monitorización de Redes (Zabbix, Cacti y Nagios)
- 🔒 Implementación de un Sistema IDS/IPS (Suricata y Wazuh)
- 🌐 Implementación de un Configurador de Hosting
- 📋 Gestión y planificación del proyecto mediante metodología Agile

Durante el desarrollo se trabajó con virtualización, automatización, monitorización, seguridad y despliegue de servicios, aplicando buenas prácticas de administración de sistemas.

**Tecnologías:**
Proxmox, Kubernetes, Docker, Ansible, Zabbix, Nagios, Cacti, Suricata, Wazuh, Linux, PHP, HTML, CSS y JavaScript.

**Link al proyecto:**
https://github.com/AlexMarquess/Projecte-Intermodular-ASIX

### 🌥️ Meteosapa

Desarrollo de una aplicación web para la visualización de datos climáticos obtenidos de una estación meteorológica basada en Arduino. El sistema procesa y muestra en tiempo real variables críticas como temperatura, humedad, presión atmosférica y velocidad del viento. Implementé la lógica para calcular y mostrar estadísticas diarias y mensuales, incluyendo medias de humedad y picos de temperatura, además de la geolocalización de la estación mediante coordenadas UTM.

**Tecnologías:** PHP, Python, HTML, CSS

**Link al proyecto:**  
https://github.com/Sgallartfanlo/meteosapa
