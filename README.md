## 🏨 Dataclysm

Sistema de gestió hotelera desenvolupat com a projecte intermodular.

L'aplicació permet gestionar hotels, habitacions, reserves, clients, treballadors i serveis mitjançant una interfície gràfica desenvolupada amb Python.

La infraestructura incorpora una base de dades PostgreSQL desplegada sobre Debian amb sistemes de còpies de seguretat automatitzades i arquitectura Actiu-Passiu per garantir alta disponibilitat.

### Tecnologies

`Python` `Tkinter` `PostgreSQL` `Debian` `SQL`

### Característiques

* Gestió completa d'hotels
* Gestió de reserves
* Sistema d'autenticació
* Exportació d'informes
* Backups automatitzats
* Rèplica Actiu-Passiu

🔗 **Repositori:**
https://github.com/Sgallartfanlo/Dataclysm
